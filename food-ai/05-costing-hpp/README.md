# Costing & HPP

Sistem menghitung biaya secara granular sampai level bahan, recipe, portion, menu, channel, dan outlet.

## Materi
- recipe costing
- yield
- edible portion
- food cost
- beverage cost
- packaging cost
- labor allocation
- overhead allocation
- contribution margin
- break-even
- price simulation
- variance analysis

Semua formula harus menyimpan unit, asumsi, periode harga, dan sumber data.
