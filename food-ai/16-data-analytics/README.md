# Data Analytics

Layer untuk mengubah data operasional menjadi insight yang dapat diaudit.

## Pipeline

Raw data → validation → cleaning → transformation → KPI → analysis → decision → experiment → feedback.

## Fokus
- sales analytics
- cohort dan repeat purchase
- menu profitability
- labor productivity
- inventory variance
- waste analytics
- supplier analytics
- forecasting
- anomaly detection
- dashboards

Tidak boleh menyamakan korelasi dengan sebab-akibat. Setiap analisis mencatat grain, periode, populasi, missing data, dan asumsi.
